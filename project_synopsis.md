# Thaif Vision AI
## An AI-Powered Image Understanding Assistant

### 1. Abstract
Thaif Vision AI is a web-based application that uses artificial intelligence to understand and analyze images. Users can upload an image, ask questions about its contents, and receive responses generated by a vision-capable AI model through the NVIDIA API. The application is developed using Python and Streamlit and provides an interactive interface with conversation history.

### 2. Problem Statement
Understanding image contents manually can be time-consuming. An AI-based image understanding assistant can help users identify objects, describe scenes, and obtain information about visual content through natural-language questions.

### 3. Objectives
- Develop a simple web interface for image uploads.
- Integrate a vision-capable AI model through the NVIDIA API.
- Allow users to ask questions about uploaded images.
- Display AI-generated responses clearly.
- Maintain conversation history during the active session.
- Provide a New Chat option to clear the current conversation.

### 4. Technologies Used
- **Programming language:** Python
- **Frontend and web interface:** Streamlit
- **AI integration:** NVIDIA API
- **Model:** Meta Llama 3.2 11B Vision Instruct
- **API client:** OpenAI-compatible Python SDK
- **Environment configuration:** python-dotenv and Streamlit Secrets
- **Version control:** Git and GitHub

### 5. System Workflow
1. The user opens the application.
2. The user uploads an image in a supported format.
3. The user enters a question about the image.
4. The application encodes the image and sends the request to the vision model.
5. The model analyzes the image and generates a response.
6. The application displays the response and updates the conversation history.
7. The user can ask further questions or start a new conversation.

### 6. System Architecture
**User → Streamlit Interface → Python Application → NVIDIA API → Vision Model → AI Response → User Interface**

### 7. Key Features
- Image upload and preview.
- Natural-language questions about images.
- AI-powered image understanding.
- Conversation history during the active session.
- New Chat functionality.
- Local execution and online deployment through Streamlit Community Cloud.
- Secure configuration of the API key without committing it to the GitHub repository.

### 8. Applications
- Educational image exploration.
- General object identification.
- Image description and scene understanding.
- Visual question answering.
- Prototype development for computer vision applications.

### 9. Limitations
The quality of responses depends on the model and image quality. AI-generated answers may occasionally be inaccurate. The application requires internet connectivity and a valid API key. Conversation history is maintained during the active session and is not stored permanently in a database.

### 10. Future Enhancements
- Persistent conversation storage.
- Support for multiple images in one query.
- Image comparison and summarization.
- Improved error handling and usage monitoring.
- Additional computer vision models and capabilities.

### 11. Conclusion
Thaif Vision AI demonstrates how a vision-capable AI model can be integrated into a web application to provide interactive image understanding. The project combines Python, Streamlit, and the NVIDIA API to deliver an accessible image question-answering experience. It also provides a foundation for future computer vision applications.
